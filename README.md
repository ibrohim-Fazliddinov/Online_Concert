# Техническое Задание — Платформа Online\_Concert

## 1.0 Цель проекта

Создать онлайн-сервис **Online\_Concert** для поиска и продажи билетов на концерты и мероприятия по модели, аналогичной сайту concert.ru.

## 2.0 Описание системы

Платформа поддерживает три основные роли:

* **Клиент** — покупает билеты и просматривает историю заказов.
* **Администрация**:

  * **Админ** — полный контроль над системой.
  * **Модератор** — проверка и публикация событий.

### 2.1 Аутентификация и регистрация

* Обязательные поля при регистрации:

  * Full Name (First + Last Name)
  * Email
  * Телефон
  * Пароль
* Вход:

  * Email или Телефон + Пароль
  * OAuth: Google

### 2.2 Функционал для Клиента

* **Каталог мероприятий**

  * Поиск и фильтрация (город, дата, жанр).
  * Сортировка по популярности, дате и цене.
* **Страница события**

  * Детали: дата, время, место, цены, схема зала.
  * Отзывы и оценки.
* **Покупка билетов**

  * Выбор мест на интерактивной схеме зала.
  * Добавление в корзину и оформление заказа.
  * Интеграция с платёжными шлюзами (Stripe, Payme, YooMoney, PayPal).
  * Получение электронного билета (PDF/QR-код).
* **Личный кабинет**

  * Профиль пользователя.
  * История покупок и статус заказов.
  * Список избранного и уведомления о похожих событиях.

### 2.3 Функционал для Организатора

* **Управление событиями**

  * Создание/редактирование/удаление концертов.
  * Загрузка иконок, баннеров и описаний.
  * Настройка схемы зала и ценовых зон.
* **Управление заказами**

  * Просмотр списка покупателей и статус оплаты.
  * Экспорт данных о продажах.
* **Аналитика и отчёты**

  * Статистика продаж по времени, городам и артикулам.
  * Реальные данные о заполнении залов.

### 2.4 Функционал для Администрации

* Модерация и валидация новых событий и организаторов.
* Управление пользователями и ролями.
* Генерация глобальных отчётов по платформе.

### 2.5 Нефункциональные требования

* **Производительность**: время ответа API не более 200 мс.
* **Масштабируемость**: горизонтальное масштабирование.
* **Безопасность**: HTTPS, bcrypt для паролей, защита от CSRF/XSS.
* **Надёжность**: резервное копирование баз данных и обработка отказов.
* **Кросс‑браузерность** и **адаптивный дизайн**.

### 2.6 Поддержка языков

Интерфейс и контент на:
 
* Русский, Английский.

## 3.0 Технологический стек

| Слой             | Технологии                                  |
| ---------------- |---------------------------------------------|
| **Backend**      | Python (FastAPI), PostgreSQL, Redis, Celery |
| **Frontend**     | React.js, Next.js, Redux, Tailwind CSS      |
| **Infra**        | Docker, Kubernetes, Nginx                   |
| **Платежи**      | Stripe, Payme, YooMoney, PayPal             |
| **Тестирование** | Jest (Frontend), Pytest (Backend)           |
| **Мониторинг**   | ELK Stack, Prometheus, Grafana              |

## 4.0 Дизайн

Использовать адаптивный шаблон с единым стилем для всех устройств.

## 5.0 Быстрый старт

1. Клонировать репозиторий и переименовать `.env.example` в `.env`.
2. Указать переменные окружения (БД, OAuth, платёжные ключи).
3. Запустить через Docker:

   ```bash
   docker-compose up -d --build
   ```
4. Создать суперпользователя:

   ```bash
   docker-compose exec web python manage.py createsuperuser
   ```
5. Открыть в браузере: `http://localhost:3000`
